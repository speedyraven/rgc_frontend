## Run it locally
1. Clone the repo:
   ```
   git clone https://github.com/speedyraven/rgc_frontend
   cd rgc_frontend
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Create a `.env` file with these variables (ask me for values, or use your own):
   ```
   [VARIABLE_NAME]=
   ```
4. Start it:
   ```
   npm run dev
   ```
